The 4x4x4 is a Rust port of cs0x7f/TPR-4x4x4-Solver (Java, Chen Shuang), Tsai's reduction with steps 3 and 4 merged, replacing the earlier plan of an own search. The 3x3x3 jar is not ported; the injected Solver trait takes its place. Licence: the README offers GPLv3 and MIT; the MIT option is taken, the NOTICE.md row and the MIT text come before any code, and every ported file names its Java origin. Two source files carry a 2014 GPL-only header, which is why the owner is asked whether to request a LICENSE file.
