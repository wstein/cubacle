Planned: the first schema line may be `scheme: western|japanese|<six letters>`; without it uppercase letters read as URFDLB. western is accepted with the alias boy. Six custom letters give the colours of U R F D L B in that order. Stating the scheme in the schema makes the file self-contained, because the same letter Z means different physical colours in different schemes. Later the same attribute is meant to apply to input and display too.
