A solution drawn as icons should also be available as a document: a Markdown file whose move icons are image files written next to it (one SVG or PNG per distinct move and cube state), or a single PNG sheet. The open question is how the icons get into the document: separate files linked from the Markdown, or data URIs inside it. Linked files keep the text readable and diff-friendly; data URIs make a single portable file. The structured solution output (moves with their phase) is the natural input for both.
