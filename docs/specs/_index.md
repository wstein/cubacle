Status: specification, not implemented yet. Nothing on this page can be run.

This section holds specifications that the owner ordered before any code exists. Unlike the rest of this manual, which describes only verified behaviour, these pages say what a feature is meant to do, so that the code can later be checked against them. When a feature is built, its page moves into the normal manual and is rewritten from measured behaviour.
